♫YTM Lyrics+

Privacy Policy

Effective date: October 12, 2026

YTM Lyrics+ reads the current song details needed to find lyrics. It sends the song title and artist, and when available the album and track duration, to LRCLIB so it can return matching lyrics.

Information the extension handles

On YouTube Music, the extension checks the current player for the track title, artist, total duration, and playback position. When the lyrics view is available, it may also read the album name. It sends a lookup to LRCLIB only when lyrics are being shown and a cached result is not available. Playback position is used locally to highlight the current lyric line and is not sent to LRCLIB.

The extension does not read or collect your name, email address, account credentials, cookies, payment details, contacts, or activity on other websites.

How information is used and shared

The extension uses the current track details only to look up lyrics. It sends an HTTPS request to LRCLIB, a third-party lyrics service. The request includes the track title and artist, with the album name and duration when available. If an exact lookup has no match, it makes a search request with the track title and artist. LRCLIB returns available synced or plain lyrics for display in YouTube Music.

LRCLIB receives these lookup details directly. Its own handling of requests is governed by its service and policies; the extension publisher does not control LRCLIB’s server-side logs or retention.

Storage and retention

YTM Lyrics+ does not operate a server and does not save track details to disk. It keeps a temporary in-memory cache while the YouTube Music page is open. That cache is cleared when the page or extension context is closed.

Limited use

Track details are used only to provide the extension’s lyric lookup and synchronization features. They are not sold, used for advertising, or used to build a profile. The only third-party transfer is the lookup request to LRCLIB, which is necessary to return lyrics. The extension publisher does not review or retain the lookup details.

Your choices

You can stop future lookups by closing the lyrics view, disabling YTM Lyrics+, or removing it from Chrome. Removing the extension clears its in-memory page cache.

Contact

For privacy questions, use the developer contact shown on the YTM Lyrics+ Chrome Web Store listing.
